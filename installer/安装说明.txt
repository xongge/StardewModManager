星露谷 Mod 管理器 v1.3
========================================

一个 Windows 上的星露谷物语 Mod 管理工具：分类管理 Mod、游戏内配置图形化编辑、
AI 汉化名称、模组更新检测、SMAPI 一键安装/修复，并把 SMAPI 的命令行窗口集成到程序里。

【怎么安装】
1. 把整个安装包文件夹解压到任意位置（不要直接在压缩包里运行）。
2. 双击「安装.hta」。
3. 选择安装位置（默认装到当前用户目录，不需要管理员权限），勾选是否创建桌面快捷方式。
4. 点「开始安装」，完成后可以直接启动。

目标电脑不需要安装 Python，程序已经打包成可执行文件。

【怎么用】
1. 打开程序 → 「设置」→ 点「自动检测」，或手动选择游戏目录（含 Stardew Valley.exe 的目录）
   与 Mod 文件夹（一般是 游戏目录\Mods）。
2. 「模组管理」页可以按分类查看、勾选启用 / 停用、双击某个 Mod 图形化修改它的 config.json。
3. 「AI 汉化名称」可以批量把英文 Mod 名翻译成中文（需要自己在设置里填 OpenAI 兼容接口的
   地址与 API Key；结果会缓存，重复使用不再消耗额度）。翻完可以点「写入 manifest」，
   这样游戏内的 Mod 列表也显示中文。
4. 「🔄 检查更新」按 Mod 的 UpdateKeys 查询 Nexus / GitHub 最新版本（Nexus 需要在设置里
   填免费的 Personal API Key）。
5. 「SMAPI 更新」页可以一键安装或修复 SMAPI（会补齐运行库文件，并自动备份原文件）。
6. 「运行控制台」页点「启动游戏」，SMAPI 的输出会显示在程序里（不再弹 CMD 黑窗），
   右上角实时统计错误 / 警告数量，按钮会变成「停止游戏」。

【配置文件在哪】
安装目录里的 config.json，可以直接用记事本修改：
  · "icon"           程序图标（可换成自己的 .ico / .png）
  · "theme_accent"   主题颜色等外观设置
  · "animations"     界面动效开关
  · "nexus_key"      Nexus API Key
  · "ai_base"/"ai_key"  AI 汉化接口
  另外 name_map.json / label_map.json 是汉化缓存，updates_cache.json 是更新检查缓存。

关于 API Key 的安全：
  · API Key 用 Windows 自带的 DPAPI 加密后保存在 config.json 的 *_dpapi 字段里，
    文件里看不到明文，而且密文与「当前 Windows 用户 + 这台电脑」绑定，
    把程序目录复制到别的电脑也无法解密。
  · 全新安装的程序不会读取旧目录里的任何设置（包括你以前填过的密钥），
    第一次启动就是干净的默认配置；想沿用旧设置的话，
    请手动把旧的 config.json / name_map.json / label_map.json 复制到安装目录。

【怎么卸载】
· 控制面板 →「程序和功能」→ 选「星露谷 Mod 管理器」→ 卸载；
· 或运行安装目录里的「卸载.hta」。
卸载会删除安装目录里的全部文件（包含配置与缓存），需要保留的话请先备份。
